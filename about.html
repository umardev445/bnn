About KhataBanao

A simple, friendly digital khata for shopkeepers and small businesses.

One straightforward goal

See how much each customer owes without complicated software. Record udhaar diya and payment received, review transactions, and print a customer statement.

Design

KhataBanao reuses the uploaded BillBanao project's signature green/cream design language, mobile bottom navigation, clean cards and gentle typography. It is a separate app built around customer credit management rather than invoices.

Technology

Standard HTML, CSS and JavaScript with local browser storage. No hosted database or required account. It can be hosted on GitHub Pages as a static website.
