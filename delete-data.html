KHATABANAO / INFORMATION

Delete your data

The web app keeps customer and transaction records in the local storage of your current browser or WebView.

Delete an entry

Open Transactions, find the record and select the delete icon. Confirm the deletion.

Delete a customer

Open a customer's ledger. Remove that customer's transactions first; then use the delete icon from the customer detail page.

Delete everything

Open Settings → Delete all records and confirm. This permanently deletes this app's current local customers and transactions while retaining app preferences. You can also clear this site's browser data in browser settings, which removes preferences as well.

Backups

Downloaded JSON/CSV files and printed statements are not automatically deleted. Remove these separately from your device, cloud drive, email, or other places you saved or shared them.

Remote records

The provided web app does not create an account or automatically upload your ledger records to a server; there is no remote customer database to request deletion from. This page describes only the provided website source, not any Android build with additional SDKs or cloud features.
